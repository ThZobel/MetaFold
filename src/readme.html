MetaFold

Laboratory Data Management & Experiment Organization

🎯 Project Overview

MetaFold is a powerful Electron-based desktop application designed specifically for laboratories and life sciences to streamline experiment organization and data management. Built with simplicity and efficiency in mind, it provides researchers with the tools they need to create structured, reproducible experimental workflows.

💡 Key Principle

MetaFold follows a modular, minimal-invasive approach that preserves existing functionality while allowing easy extension and customization for different laboratory needs.

⚡ Core Features

📂 Automated Folder Structures

Create standardized folder hierarchies for experiments with customizable templates. Ensure consistency across all your research projects.

🧪 Metadata Management

Configure and manage experiment metadata with dynamic forms, validation, and automatic JSON generation for data consistency.

📊 Data Visualization

Visualize experiment data and metadata structures using integrated JSONCrack technology for better data understanding.

👥 Multi-User Support

Support for multiple user accounts with secure credential storage and user-specific template management.

🔍 Project Discovery

Automatically scan and discover existing projects with metadata analysis and intelligent project organization.

🔧 Template System

Advanced template management with file-based storage, sharing capabilities, and version control for laboratory workflows.

🚀 Quick Start Guide

Get started with MetaFold in just a few simple steps:

  1. Launch MetaFold
    Open the application and select or create a user profile for your laboratory work.
  2. Create Your First Template
    Use the "New Template" button to create a folder structure or experiment template that fits your research needs.
  3. Configure Project Settings
    Set your base directory and project naming conventions in the enhanced project setup section.
  4. Design Metadata Forms
    Use the metadata editor to create custom forms for capturing experiment parameters and data.
  5. Create Your Project
    Apply your template to create a new project with automated folder structure and metadata files.
  6. Integrate with Lab Systems
    Connect to elabFTW and OMERO through the settings panel to synchronize your data across platforms.

🛠️ Development Guidelines

🎯 Core Development Principles

  • Preserve Existing Functions: Never change existing function names during updates
